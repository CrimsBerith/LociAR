# Nocturnal screenshot backgrounds

Five full-bleed RGB PNG panels, each **1320 × 2868 pixels**. They use the LociAR
night gradient (`#08101A` → `#050814`) and restrained mint (`#38E0B8`) ambient light.
The top quarter is reserved for localized headlines; the middle/lower center is
reserved for real app screenshots. No phones, screens, UI, lettering or service
logos are baked into these panels.

| Panel | Direction |
| --- | --- |
| `bg-01.png` | Soft diagonal mint light along the left wall edge |
| `bg-02.png` | Quiet vertical wall plane with lower-right reflected light |
| `bg-03.png` | Diffuse lower mint glow; balanced central composition |
| `bg-04.png` | Right-edge mint light with a cooler navy left wall |
| `bg-05.png` | A closing panel with very soft reflected light at the base |

The panels share one restrained palette and are intended to form a coherent
series. Generated art was exported to the required pixel canvas as RGB PNG.

Claude will supply the composition script. The release owner must capture and
place **real iPhone screenshots** in the device area; these backgrounds alone
are not App Store screenshots. Use genuine nearby pins and real text/link notes,
and keep localized headlines separate. Do not draw or generate a substitute app
screen. No Swift, localization catalog or existing screenshot was changed here.
